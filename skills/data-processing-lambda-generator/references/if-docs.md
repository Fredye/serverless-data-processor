# IF 文档解析规则

## 常见格式

- Excel（.xlsx）：IF定義書、IF変換説明書 常为独立 sheet 或工作簿，用电子表格能力读取全部 sheet 与表头。
- CSV / Markdown 表格 / Word：按表格列解析。

## IF定義書 典型列

`項番 | 項目ID（物理名） | 項目名（論理名） | 型 | 桁数/長さ | 必須 | 形式/パターン | 初期値 | 例 | 備考`

列名可能略异（`No.`、`フィールド名`、`データ型`、`必須/任意`、`フォーマット`、`デフォルト値`），按语义识别。

### 型与 Python 类型映射

| 文档写法 | Python 类型 |
|---|---|
| 文字列 / コード / ID | str |
| 整数 / 件数 | int |
| 数値 / 金額 | Decimal |
| 日付（YYYYMMDD 等） | date（按转换规则输出） |
| 日時 | datetime（UTC ISO） |
| フラグ（0/1、Y/N） | bool 或 str |

### 必须性

- 必须：`○`、`必須`、`必須○`、`REQ`、`Required`
- 任意：`任意`、`-`、空白、`OPT`

### 形式/パターン

`YYYYMMDD`、`YYYY-MM-DD`、`HHmmss`、正規表現、`半角数字` 等，全部在 `validate()` 中校验。

## IF変換説明書 典型列

`変換元IF | 変換元項目 | 変換先（テーブル/DB） | 変換先項目 | 変換ロジック | 変換先型 | 変換先桁 | 必須 | デフォルト値 | 備考`

### 変換ロジック 常见写法与实现

| 文档写法 | 实现 |
|---|---|
| そのまま / コピー | 直接赋值 |
| 型変換 | `int()` / `Decimal()` / `str()` |
| 大文字化 / 小文字化 | `.upper()` / `.lower()` |
| トリム | `.strip()` |
| ゼロ埋め / パディング | `.zfill(n)` / `.ljust(n)` |
| 日付形式変換 | `datetime.strptime` / `strftime` |
| 計算 | 数量×単価 等（用 Decimal） |
| 連結 | f-string / `+` |
| コード変換 / マッピング | 映射 dict / 条件 |
| 条件分岐 | if / 三元表达式 |
| NULL/空値処理 | 默认值 / 跳过 / 报错（按備考） |
| 固定値 | 常量赋值 |

## 每个 IF 的解析产物

1. IF 标识（ID/名称）：用于目录与函数命名。
2. 输入字段列表：字段名、类型、必须性、校验规则（必填/类型/范围/格式/枚举）。
3. 输出字段列表：目标表/DB、字段名、类型、来源（変換元項目 + 変換ロジック）。
4. 输出表名与主键：用于 template.yaml 与幂等写入。
5. 特殊规则：默认值、NULL 处理、代码映射、条件分支。

## 处理要点

- 列名不固定，以语义判断（項目ID vs 項目名；必須 vs 任意）。
- 一个 IF 可能输出多张表；一个输出字段可能来自多个输入字段（计算/联结/条件）。
- 无法解析的规则放入「待确认清单」，不要臆造业务规则。
